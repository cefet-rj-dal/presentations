# Presentations

Apresentações e materiais de divulgação do grupo DAL.

## Apresentações

1. [SBBD 2026 - Correlation](https://github.com/cefet-rj-dal/presentations/blob/main/2026-04-SBBD-Correlation.pdf): apresentação sobre análise de correlação em séries temporais e dados científicos.
2. [SBBD 2026 - CP Autoencoders](https://github.com/cefet-rj-dal/presentations/blob/main/2026-04-SBBD-CP-Autoencoders.pdf): apresentação sobre o uso de autoencoders baseados em decomposição CP para modelagem e análise de dados multidimensionais.
3. [SBBD 2026 - Filtro Anomalia](https://github.com/cefet-rj-dal/presentations/blob/main/2026-04-SBBD-FiltroAnomalia.pdf): apresentação sobre técnicas de filtragem e detecção de anomalias em dados.
4. [SBBD 2026 - Model Manager](https://github.com/cefet-rj-dal/presentations/blob/main/2026-04-SBBD-ModelManager.pdf): apresentação sobre gerenciamento, organização e acompanhamento de modelos analíticos.
5. [SBBD 2026 - WARMA](https://github.com/cefet-rj-dal/presentations/blob/main/2026-04-SBBD-WARMA.pdf): apresentação sobre modelos WARMA aplicados à análise de séries temporais.
6. [BRESCI 2026 - Hybrid Data Publishing](https://github.com/cefet-rj-dal/presentations/blob/main/2026-05-Bresci-HybridDataPublishing.pdf): apresentação sobre publicação híbrida de dados e estratégias para disponibilização de conjuntos de dados científicos.
